# Как нарисовать своего питомца (инструкция для художника)

Этот файл — для человека с карандашом, а не для робота. Папа разберётся с остальным.

## Что нужно

- Файл `Resources/Art/pet-template.svg` — заготовка с котом.
- Бесплатный редактор: Figma (в браузере) или Inkscape. Открыть в нём файл-template.

## Три правила (важно!)

1. **Рисуй ВНУТРИ слоёв.** Слева в списке слоёв есть имена: `body`, `ear-left`, `tail`, `eye-left`... Нарисуй своё прямо поверх старого внутри того же слоя, а старое удали. Имена слоёв — это волшебные слова, которые оживляют картинку.
2. **Не переименовывай и не склеивай слои.** Если слоя нет — анимация этого места не заработает.
3. **Не вылезай за квадрат.** Всё должно помещаться в холст 400×400.

## Что оживёт само

| Слой | Что будет делать |
|---|---|
| `body` | дышать, приседать от радости |
| `ear-left`, `ear-right` | шевелиться, прижиматься |
| `tail` | вилять |
| `eye-left`, `eye-right` | моргать |
| `pupil-left`, `pupil-right` | смотреть за мышкой |
| `cheek-*` | румянец |
| `belly-mark` | метка на животе (сердечко, звёздочка — что хочешь) |
| `accessory` | бантик/листочек, качается |

Хочешь собаку вместо кота? Уши сделай висячими, хвост колечком — слои те же, а зверь уже другой. Хочешь дракона? Крылья нарисуй в `accessory` и `tail` подлиннее. Слои решают, где что шевелится, а не как выглядит.

## Цвета

Можешь красить как хочешь — потом папа подберёт палитру. Тёмный контур вокруг (как у Kiwi) смотрится лучше всего.

## Готово? Отдай папе файл

Сохрани как `.svg` с тем же именами слоёв и отдай папе. Дальше он запустит проверку и твой зверь поселится рядом с Kiwi в настройках.

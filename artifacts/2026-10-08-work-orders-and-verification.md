## 2. Почему «в сборке не видно агентов»

- На рабочем столе живёт **golden-сборка от 7 октября** — она старше F0–F5: в её бинаре 27 агентских строк против 64 в свежей, а знаков ожидания (`?`, y/n) там нет вообще. Смотреть надо на свежую сборку в `sweet-no-sleep-pr9/dist/`.
- Даже в свежей сборке индикаторы появляются **только когда приходят события агента** — хуки реальных агентов (Claude Code и др.) на машине ещё не установлены (см. `presets/README.md`).
- Счётчика активных агентов **на персонаже нет** — только в дашборде и настройках; это и добавляет [#15](https://github.com/bestdeejay-design/sweet-no-sleep/issues/15).
- Если запущены две копии приложения (dev + golden) с одним bundle id, URL-событие может уйти не тому инстансу — это тоже отмечено в [#15](https://github.com/bestdeejay-design/sweet-no-sleep/issues/15).

```bash
cd ~/Projects/sweet-no-sleep-pr9
./Scripts/agent-event.sh start demo-a                        # огонёк «в работе»
./Scripts/agent-event.sh waiting demo-a "Approve deploy?"    # янтарный свет + ?/! + пузырь y/n
./Scripts/agent-event.sh done demo-a                         # всё гаснет
```

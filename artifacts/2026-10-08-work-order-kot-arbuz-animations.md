# Ворк-ордер #17: анимации Котя-арбуза — 2026-10-08

**Что это:** задача арене на паритет анимаций спрайт-персонажа с процедурным
Киви. Создана по итогам приёмки PR #16 и обратной связи мейнтейнера:
«кот-арбуз хорош, но статичен — ножки и хвостик должны двигаться, глазки
всегда на курсор, эмоций столько же, сколько у Киви, сердечки при
глажении, листики/звёздочки с лунной пылью, ≥60 fps».

**Issue:** https://github.com/bestdeejay-design/sweet-no-sleep/issues/17
**База:** `arena/2ef8d8bb-sweet-no-sleep` @ `5a114c9` (голова PR #16).

## Разрыв «спрайт против Киви» (по коду PR #16)

| Возможность | Kiwi (процедурный) | Kot-Arbuz (спрайт) |
|---|---|---|
| Слои | голова/тело/хвост/морда рисуются отдельно | body.png + tail.png, всё остальное запечено |
| Глаза | следят за курсором (`cursorGaze`), мигание, закрываются | статичные, запечены в body.png |
| Голова | покачивание, наклоны | нет слоя — нет движения |
| Лапы | шаг/позы | нет слоёв — «ходьба» это наклон корпуса |
| Хвост | живой | есть (качание + подъём на waiting) — принято |
| Эмоции | 11 mood, все различимы | те же 11 mood, но меняется только поза корпуса |
| Сердечки при поглаживании | есть (`drawCheekHeart`) | нет (сердечки только в celebrate-эффекте) |
| Скины | 3 (kiwi/moonlight/strawberry) | 1 |
| Аура/halo | mood-тонированная | есть `drawHalo` — сохранить |

## Состав заказа (кратко)

- **P0:** слои head/legs/tail + вектоные глаза на якорях (взгляд за курсором,
  мигание, закрытые в resting), walk-цикл лап, покачивание головы;
  расширение `pet.json` и `prepare-character-assets.py`.
- **P1:** все 11 эмоций различимы у спрайта («арбузный» флэвор — маппинг
  предлагает арена), сердечки при клике-глажении, частицы leaves /
  stars+moon dust / berry hearts на спрайт-пути.
- **P2:** 3 скина у кота-арбуза, ≥60 fps на 45–170 pt, Reduce Motion —
  статичная поза, валидация паков.
- **Приёмка на Маке:** клик-трейл из 7 пунктов (взгляд по углам, мигание,
  прогулка с шагом, сердца, танец с частицами, три скина, fps).

## Стенд

Кот-арбуз запущен на просмотр мейнтейнеру: worktree-сборка PR #16,
170 pt, roaming on. Настройки вернутся к moonlight/45 pt после просмотра.

# Support

This project is a community macOS app. Here is where to get help.

## Questions and usage help

- Open a [GitHub issue](https://github.com/bestdeejay-design/sweet-no-sleep/issues)
  with the `bug` or `question` template.
- Check [README.md](README.md) for installation, build, and settings guidance.
- Check [docs/](docs/) for architecture, media, and release notes details.

Please search existing issues before opening a new one.

## Security

Do not report security vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md) instead.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the development workflow, coding
standards, and how to submit a pull request.
